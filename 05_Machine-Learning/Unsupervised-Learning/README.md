## Topics

| Topic | 핵심 내용 |
|---|---|
| Clustering | 비슷한 데이터를 그룹으로 분류 |
| K-Means | Centroid를 기준으로 군집화 |
| DBSCAN | 데이터 밀도를 기준으로 군집화 및 Noise 탐지 |
| Association Rule | 함께 나타나는 항목의 관계 탐색 |
| Apriori | 빈발 항목집합 탐색 |
| Support / Confidence / Lift | 연관규칙 평가 |
