# 다중선형회귀(Multiple Linear Regression)

## 학습 내용

공부 시간과 과외 횟수를 독립변수로 사용하여 성적을 예측하는 다중선형회귀 모델 예시

- 입력 변수
  - `x1`: 공부 시간
  - `x2`: 과외 횟수
- 목표 변수
  - `y`: 성적
- 경사하강법을 직접 구현하여 가중치와 편향을 학습
- 평균제곱오차(MSE)를 기준으로 모델의 오차 측정
- 실제 데이터와 학습된 회귀평면 시각화

---
## 다중선형회귀

```text
예측 성적 = w1 × 공부 시간 + w2 × 과외 횟수 + b
```
- `w1`: 공부 시간이 성적에 미치는 영향
- `w2`: 과외 횟수가 성적에 미치는 영향
- `b`: 모든 입력값이 0일 때의 기준값인 편향

---

## 기계학습 접근법

### 손실 함수(Loss Function)

손실 함수는 **한 개의 데이터에 대한 예측 오차**를 나타낸다.
예를 들어 실제 성적이 90점이고 예측 성적이 85점이라면

```text
오차 = 실제값 - 예측값
     = 90 - 85
     = 5
```

제곱오차를 사용하면

```text
손실 = (실제값 - 예측값)²
     = 25
```

오차를 제곱하면 양수와 음수 오차가 서로 상쇄되지 않고, 
큰 오차에 더 큰 패널티

---

### 비용 함수(Cost Function)

비용 함수는 **전체 학습 데이터의 손실을 평균한 값**이다.
이번에는 평균제곱오차(MSE)

```python
loss = np.mean((y - y_hat) ** 2)
```

```text
MSE = 모든 제곱오차의 합 / 데이터 개수
```
비용 함수의 값이 작을수록 모델의 예측값이 실제값에 가깝다

---

### 목적 함수(Objective Function)

목적 함수는 학습 과정에서 **최소화하거나 최대화하려는 전체 기준**이다.
이번에는 별도의 규제항이 없으므로 목적 함수와 비용 함수가 동일

```text
목적: MSE를 가능한 작게 만들기
목적 함수 = 비용 함수 + 규제항
```

---

### 최적화(Optimization)

최적화는 목적 함수의 값을 가장 작게 만드는 파라미터를 찾는 과정
이번에는 경사하강법

```python
w1 -= learning_rate * w1_gradient
w2 -= learning_rate * w2_gradient
b -= learning_rate * b_gradient
```

기울기는 손실이 증가하는 방향
따라서 기울기의 반대 방향으로 가중치와 편향을 이동시키면 손실을 줄일 수 있다.

---

### 학습률(Learning Rate)

학습률은 한 번의 업데이트에서 파라미터를 얼마나 이동할지 결정

```python
learning_rate = 0.01
```

- 너무 크면
  - 최적점을 지나칠 수 있음
  - 손실이 커지거나 발산할 수 있음
- 너무 작으면
  - 학습 속도가 매우 느림
  - 많은 반복 횟수가 필요함

적절한 학습률을 선택해야

---

## 학습 과정

```text
가중치와 편향 초기화
        ↓
예측값 계산
        ↓
실제값과 예측값의 오차 계산
        ↓
MSE 계산
        ↓
각 파라미터의 기울기 계산
        ↓
경사하강법으로 파라미터 갱신
        ↓
지정된 횟수만큼 반복
```

---

## 주요 코드

### 예측값 계산

```python
y_hat = w1 * x1 + w2 * x2 + b
```

### 평균제곱오차 계산

```python
error = y - y_hat
loss = np.mean(error ** 2)
```

### 기울기 계산

```python
w1_gradient = (-2 / n) * np.sum(x1 * error)
w2_gradient = (-2 / n) * np.sum(x2 * error)
b_gradient = (-2 / n) * np.sum(error)
```

### 파라미터 업데이트

```python
w1 -= learning_rate * w1_gradient
w2 -= learning_rate * w2_gradient
b -= learning_rate * b_gradient
```

## 정리

- 다중선형회귀는 여러 입력 변수를 이용하여 연속값 예측
- 가중치: 각 입력 변수가 예측 결과에 미치는 영향
- 편향: 회귀식의 기준점 조정
- 손실 함수: 개별 데이터의 오차
- 비용 함수: 전체 데이터 손실의 평균
- 목적 함수: 학습 과정에서 최적화하려는 기준
- 경사하강법: 기울기의 반대 방향으로 파라미터를 이동
- 학습률: 파라미터의 한 번당 이동 크기를 결정
- 이번 코드의 학습 데이터가 4개뿐이므로 실제 모델 성능을 평가하기에는 부족
- (그냥 경사하강법의 원리를 이해하기 위한 실습이었던 것으로)
